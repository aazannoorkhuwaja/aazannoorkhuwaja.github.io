## Pharma-Khaato

**Pharmacy POS & relational database system** · Python · MySQL · CustomTkinter

Pharma-Khaato replaces manual pharmacy inventory and customer-credit records with a desktop system built around a relational database. It tracks medicine batches, expiry dates, stock levels, sales, receipts, and running customer balances.

**What makes it interesting:** checkout operations use database transactions to protect data integrity, while batch handling supports FEFO (First-Expiry-First-Out) inventory decisions.

**My contribution:** database schema design, RDBMS integration, and application architecture as part of a team project.

[View Pharma-Khaato on GitHub](https://github.com/aazannoorkhuwaja/Pharma-Khaato)

## Network Intrusion Detection System

**AI/ML classification project** · Python · scikit-learn · Pandas · Jupyter

A network-traffic classification project comparing rule-based and machine-learning approaches for identifying normal versus attack connections. The work explores a simple reflex-agent baseline, supervised models, clustering, and evolutionary feature selection.

**Measured result:** the strongest evaluated classifier, KNN with `k=1`, achieved **95.58% test accuracy** and an **F1 score of 0.9563** on the project dataset.

**My contribution:** exploratory data analysis, the simple-reflex-agent baseline, and supervised machine-learning experiments.

[View Network Intrusion Detection on GitHub](https://github.com/aazannoorkhuwaja/Network-Intrusion-Detection)

## FlashYT

**Cross-platform browser tooling** · Python · Native Messaging · yt-dlp · ffmpeg

FlashYT adds a download action directly to supported browser interfaces and connects that UI to a local Python host. Instead of sending video data through a third-party cloud service, the workflow runs on the user's own machine.

The project grew beyond a classroom-style prototype into a product-shaped open-source tool with browser integration, host communication, installation flows, release packaging, troubleshooting, and support across desktop platforms, with Android work included in the repository.

The most valuable part of this project was learning how much engineering sits between "the feature works on my machine" and "another person can actually install and use it."

[View FlashYT on GitHub](https://github.com/aazannoorkhuwaja/FlashYT)

## FYP Management System

**Software design & Java desktop application** · Java · Swing · MVC

A role-based Final Year Project management platform for students, supervisors, and administrators. It covers proposal submission, supervision workflows, peer review, inactivity monitoring, and role-specific dashboards.

The implementation uses an MVC structure, object-oriented inheritance, centralized data management, and SHA-256 password hashing. The project was developed collaboratively for the Software Design & Analysis course.

[View FYP Management System on GitHub](https://github.com/aazannoorkhuwaja/FYP-Management-System-SDA-Project)
