I’m **Aazan Noor Khuwaja**, a Computer Science undergraduate at **FAST-NUCES Peshawar**.

I’m most interested in the point where computer-science concepts become working systems: databases that need to preserve integrity, software that has to be usable by someone else, and AI models that should be evaluated instead of simply described.

That mindset has shaped the projects I’m proudest of so far. I’ve worked on a pharmacy inventory and credit-management system with transactional database logic, a network-intrusion detection project that compared multiple AI/ML approaches, a cross-platform browser tool using native messaging, and a Java FYP-management platform built around software-design principles.

## What I care about

- **Software engineering:** architecture, requirements, object-oriented design, debugging, and building beyond the first working prototype.
- **Databases:** relational modeling, SQL, normalization, transactions, and using data structures that match the real business workflow.
- **AI & machine learning:** understanding assumptions, comparing approaches, measuring results, and learning where simpler methods are enough.
- **Linux & open source:** Linux is part of my regular development environment, and Git/GitHub are central to how I learn, document, and collaborate.
- **Problem solving:** I keep strengthening algorithms and data structures through coursework, practice, and small focused repositories.
